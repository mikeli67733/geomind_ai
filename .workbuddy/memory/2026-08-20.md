### 关键经验
- **QGIS 插件禁止顶层绝对导入**，一律相对导入（插件以包名加载，仅父目录在 sys.path）；ui/local_tools/ 到 core/tools/utils 是三级相对导入 `...core`
- **py_compile 查不出 NameError**（用但没导入），要用作用域感知 AST 名称解析检查器
- 插件目录 `C:\Users\Administrator\AppData\Roaming\QGIS\QGIS3\profiles\default\python\plugins\geomind_ai` 是**符号链接指向 G:\geomind\geomind_ai**，改动即时生效，无需手动同步
- 做"专业化"重构时勿删 emoji 视觉元素（v4.0 101 处曾被误删，从 git show HEAD~N:file 找回恢复）；git 历史是找回 UI 细节的可靠来源
- venv/pytest 在 Windows 上反复损坏（pip safe-delete 机制），测试移到 CI，本机不再折腾

## 解译范围过大保护（下午，续）
- 需求：图层当前页面范围太大时提醒并停止推送裁图与解译
- **utils/extent_guard.py**：`estimate_extent_pixels()` 范围按栅格分辨率折算像素（CRS 不一致先变换到图层 CRS）；`check_extent_too_large()` 返回 (超限, 文案)
- **core/constants.py**：MAX_EXTENT_PIXELS=2000 万像素、MAX_EXTENT_SIDE_PIXELS=12000（防超长条带）；**core/exceptions.py** 新增 ExtentTooLargeError
- 三层拦截：① base_task_widget._run_task 弹窗「解译范围过大」（默认停止，可仍然继续）；② skill_dispatcher 三个云端 AI 技能创建任务前 raise；③ interpret_task.run() 起点兜底（任何入口都不会真的裁图上传）
- 经验：云端任务入口多（UI 页 + Copilot 技能 + 任务类），安全拦截做「入口预检 + 任务层兜底」双层
- 用户反馈"继续改小，因为要上传到服务器带宽不支持"：MAX_EXTENT_PIXELS 2000万→**500万**、MAX_EXTENT_SIDE_PIXELS 12000→**4000**；guard 文案加"预计上传约 X MB"（JPEG q75 按 0.8B/px 估算），拦截点均动态复用 guard 文案改常量即全局生效；注释标明可再调（如 300万/3000）
