# GeoMind AI：历史记录页 + 每页历史文件夹回溯 + 记忆功能

## 目标
1. 前端新增「历史」页面，浏览/搜索全部运行记录
2. 每个页面一个文件夹，每次运行一个子文件夹，保存参数/日志/结果副本，支持回溯（查看、打开文件夹、加载结果图层、重新执行）
3. 记忆功能「越用越智能」：记住每页上次/最常用参数与图层，打开页面自动预填；历史页展示常用工具与使用统计

## 存储设计（QGIS 用户配置目录，跨重启持久化、可写）
```
<QgsApplication.qgisSettingsDirPath()>/geomind_ai/
├── history/
│   ├── copilot/                # AI 对话页
│   │   └── 20260830_203000/    # 一次会话一个文件夹
│   │       ├── session.json    # 会话元数据（起止时间、消息数）
│   │       └── chat.jsonl      # 逐条消息
│   ├── task_spectral_index/    # 本地工具页（每页一文件夹）
│   │   └── 20260830_203000/    # 每次运行一个子文件夹
│   │       ├── record.json     # 元数据+参数+输入输出+状态+耗时
│   │       ├── params.json     # 参数快照（回溯/重新执行预填用）
│   │       ├── log.txt         # 运行日志摘要
│   │       └── outputs/        # 结果文件副本（<20MB 才复制，大文件只记路径）
│   └── task_landuse_multi/ ... # 云端 AI 任务页（8 个）
└── memory.json                 # 记忆库
```

## 新增模块

### 1. `core/history.py` — HistoryStore（base_dir 可注入便于测试）
- `record_run(page_key, title, status, params, summary, input_layers, output_files, log_text, duration_ms)`：建 `history/<page_key>/<时间戳>/` 文件夹，写 record.json/params.json/log.txt，小文件（<20MB）复制到 outputs/
- `record_copilot_session(...)` / `append_copilot_message(...)`：对话保存
- `list_records(page_key=None, keyword="", limit=300)`：扫描各页文件夹返回倒序记录（损坏 JSON 跳过）
- `get_record(folder)` / `delete_record(folder)` / `clear_page(page_key)` / `open_folder(folder)`（QDesktopServices 打开资源管理器）

### 2. `core/memory.py` — MemoryStore（memory.json）
- `record_usage(page_key, params, layers)`：更新每页最近参数、各参数取值频次 `freq[page_key][字段][值]+=1`、使用次数、最近使用时间、最近图层
- `suggested_params(page_key)`：按频次返回该页最常用参数（智能推荐）
- `last_params(page_key)` / `last_layers(page_key)`
- `most_used_pages(n)` / `recently_used(n)` / `stats()`（历史页展示用）

### 3. `ui/param_memory.py` — 参数快照助手（本地工具通用预填）
- `collect_param_snapshot(widget)`：遍历控件树，按 objectName 记录 QComboBox(存 data+index)/QSpinBox/QDoubleSpinBox/QCheckBox/QLineEdit/QTextEdit/QgsMapLayerComboBox(存图层 id)
- `apply_param_snapshot(widget, snapshot)`：按 objectName 还原（图层按 id 从 QgsProject 找回）
- 预填规则：优先频次最高值，其次最近一次值 ——「越用越智能」

### 4. `ui/history_page.py` — 历史页面
- 顶部：搜索框 + 页面筛选下拉 + 「刷新」「清空」按钮 + 记忆概览条（常用工具 Top3 / 最近使用 / 记录总数）
- 中部左右分栏：左侧记录列表（状态图标+页面+摘要+时间），右侧详情（完整参数 JSON、日志、输入输出、结果文件路径）
- 底部操作：🖱 加载结果图层（有副本用副本）、↩ 重新执行（跳转该页并预填参数，本地工具走快照、AI 页走显式 apply）、📁 打开文件夹、🗑 删除记录
- `set_page_filter(page_key)`：从某页跳过来时自动筛选该页

## 修改现有文件

### 5. `ui/dock_widget.py`
- 顶栏新增「🕘 历史」按钮（设置旁），stack 注册历史页（index 2）
- 新增 `show_history_page(filter_key=None)`；`_register_page` 给每个页面设置 `widget.page_key / page_title`
- 新增 `prefill_page_params(page_key, params)`：查页面实例并调用其 `apply_saved_params(params)`
- `closeEvent` 时 finalize Copilot 会话

### 6. `ui/base_task_widget.py`（云端 AI 8 页，集中挂接）
- `_run_task`：捕获 JSON 安全的参数快照（图层对象转为 id/名称/源路径）
- `_on_finished_ok` / `_on_finished_error` / `_on_cancelled`：分别记录 status=ok/failed/cancelled 的历史 + 写入记忆
- 新增 `apply_saved_params(params)` 基类默认空实现；LanduseMultiTaskWidget 还原勾选类别、Sam3TaskWidget 还原提示词、ChangeDetectionTaskWidget 还原 T2 图层
- 运行区右上角加「🕘 历史」小按钮 → `dock.show_history_page(filter_key=self.page_key)`

### 7. `ui/local_tools/base.py` + 10 个工具页
- 基类 `BaseLocalToolWidget` 新增：`page_key/page_title` 属性、`record_local_run(status, summary, params, output_paths, error)`（写历史+记忆）、`apply_saved_params(params)`（调 param_memory 快照还原）、`show_history()` 小按钮（`_build_ui` 后自动插到布局顶部，10 页通用）
- 10 个工具页：给参数控件补 `setObjectName`（index_combo/spin_k/spin_iter/dem_type_combo 等，约 30-40 行）；各 run 方法成功/异常路径各加一行 `self.record_local_run(...)`，并捕获算法返回的输出路径（如 `out = kmeans_cluster(...)`）
- 页面打开时自动预填记忆参数 + 上次图层（`apply_saved_params(memory.suggested_params(page_key))`）

### 8. `ui/copilot_widget.py`（AI 对话页）
- `_send_msg` 将用户消息与助手回复追加到当前会话 `history/copilot/<时间戳>/chat.jsonl`（首次发送时建会话文件夹，清空会话/关闭 Dock 时 finalize）
- 历史页可查看对话会话列表与内容

## 说明
- 账号页无"运行"概念，不记录历史；记录范围 = 10 本地工具 + 8 AI 任务 + AI 对话
- 结果文件仅 <20MB 复制到历史文件夹（按你确认的方案），大文件只记路径
- 历史/记忆数据存在 QGIS 用户配置目录，不会污染插件安装目录
