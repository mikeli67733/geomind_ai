# geomind_ai
GeoMind AI - 遥感大模型智能解译 QGIS 插件

## 账号与套餐

插件需要先登录才能使用（面板顶部「账号与套餐」区域可直接注册/登录），配套三档套餐：

1. **免费版**：注册即自动开通，每天可免费解译 5 次
2. **包月付费**：99 元 / 30 天，不限每日次数，仅支持支付宝扫码支付（面板里点「套餐与升级」-> 生成付款码）
3. **定制服务 / 私有化部署**：按解译面积人工报价，扫码联系作者（不走自动支付）

登录/套餐/支付宝支付相关的服务端实现在 `../backend/` 目录，需要单独部署，
详见该目录下的 README。插件里“服务地址”应填写这个账号网关的地址。

插件本身运行依赖：`requests`，如果想在支付页面直接显示二维码图片而不是纯链接文字，
再装一个 `qrcode`（`pip install qrcode`）；没装的话会自动退化成显示链接+复制按钮。
